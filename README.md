# schuylerk

个人 GitHub Pages，放了一些小工具。

## 项目

| 项目 | 说明 | 链接 |
|------|------|------|
| **GIF 生成** | 选择多张 PNG 或文件夹 → 预览动画 → 导出 GIF（支持透明背景） | [gif-gen](https://schuylerk.github.io/gif-gen/) |
| **抠图工具** | 浏览器内抠图：色度键、魔棒、笔刷、AI 抠图（imgly）、一键去底 | [matting](https://schuylerk.github.io/matting/) |

## 本地

- **GIF 生成**：见 [pngseqframe](https://github.com/schuylerk/pngseqframe)（Vite 构建，部署到本仓库的 `gif-gen/`）
- **抠图工具**：见 [matting](https://github.com/schuylerk/matting)（Vite 构建，部署到本仓库的 `matting/`）

首页：[https://schuylerk.github.io/](https://schuylerk.github.io/)
